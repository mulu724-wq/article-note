# 기사 프로젝트 노트

미국 유학, 지금 과연 의미가 있는 선택인가.
트럼프의 이민 정책이 바꾼 미국의 교육 정책과 유학생의 미래 지도를 다루는 기사 프로젝트의 작업 노트 페이지입니다.

별도의 빌드나 설치 없이 HTML 파일 하나로 동작합니다.

## 구성

| 섹션 | 내용 |
| --- | --- |
| 프로젝트 한 줄 | 프로젝트 요약 한 문장 |
| 팀 이름과 역할 | 팀 이름, 구성원별 역할 |
| 주제 | 대주제와 앵글 (앵글은 "내일 정함"으로 비워 둠) |
| 할 일 체크리스트 | 5개 항목, 진행 현황 표시 |
| 날짜별 기록 | 11/18부터 하루 한 줄 기록, 항목 추가 가능 |

## 사용 방법

1. 저장소를 내려받거나 복제합니다.
2. `article-project-note.html`을 브라우저에서 엽니다.
3. 모든 텍스트 칸을 클릭해서 바로 수정합니다.

```bash
git clone <저장소 주소>
cd <저장소 폴더>
open article-project-note.html   # Windows는 start, Linux는 xdg-open
```

## 동작 방식

- 입력한 내용과 체크 상태는 브라우저의 localStorage에 저장됩니다. 같은 브라우저, 같은 파일 경로에서만 유지되며, 다른 기기나 브라우저와는 공유되지 않습니다.
- 브라우저 데이터를 지우면 저장된 내용도 함께 사라집니다. 중요한 내용은 별도로 백업해 두세요.
- "+ 기록 추가" 버튼을 누르면 오늘 날짜가 채워진 기록 줄이 추가됩니다.
- 인쇄 시 배경은 흰색으로, 추가 버튼은 숨겨집니다.
- 모바일 화면 폭에 맞춰 레이아웃이 조정됩니다.

## 디자인

하이엔드 매거진의 절제된 분위기를 기준으로 색과 서체를 잡았습니다. 색상은 파일 상단의 CSS 변수에서 바꿀 수 있습니다.

| 변수 | 색 | 용도 |
| --- | --- | --- |
| `--ivory` | Warm Ivory `#F5F0E6` | 배경 |
| `--charcoal` | Charcoal `#2A2A2A` | 본문, 주요 선 |
| `--olive` | Muted Olive `#6B7152` | 체크 표시, 보조 라벨 |
| `--oxblood` | Oxblood `#5C1E27` | 날짜, 앵글, 강조 |
| `--stone` | Stone `#B9B2A5` | 구분선, 안내 문구 |

서체는 Cormorant Garamond, Noto Serif KR, Noto Sans KR을 Google Fonts에서 불러옵니다. 오프라인이거나 불러오지 못하면 시스템 기본 세리프, 산세리프 서체로 대체됩니다.

## GitHub Pages로 공개하기

저장소의 Settings > Pages에서 배포 브랜치를 선택하면 웹에서 열어볼 수 있습니다. 이때 파일명을 `index.html`로 바꾸면 주소 뒤에 파일명을 붙이지 않아도 됩니다. 노트 내용이 외부에 공개되므로, 공개 전에 팀 이름과 기록에 민감한 내용이 없는지 확인하세요.
